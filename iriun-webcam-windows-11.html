Windows 11 guide

Iriun Webcam on Windows 11 — setup, permissions & fix guide

Install Iriun Webcam on Windows 11. Enable camera privacy settings, add to firewall, fix SmartScreen and resolve Windows 11 specific connection and detection issues.

Iriun Webcam 2.9.5 is compatible with Windows 11. The main differences from Windows 10: stricter camera privacy settings, enhanced firewall rules and updated driver signing requirements.
Windows 11 setup

Install Iriun Webcam on Windows 11

  • 1

    Download and install

    Download IriunWebcam-2.9.5.exe and run it. If Windows 11 SmartScreen appears, click More info → Run anyway.

  • 2

    Allow camera access in Windows 11

    After install: Settings → Privacy & security → Camera. Make sure these are all turned ON:

    • Camera access
    • Let apps access your camera
    • Let desktop apps access your camera
  • 3

    Allow through Windows 11 Firewall

    Settings → Privacy & security → Windows Security → Firewall & network protection → Allow an app through firewall → add IriunWebcam.exe for both Private and Public networks.

  • 4

    Reboot and test

    Restart Windows 11, open the Iriun PC client, connect your phone and test in your video app.

FAQ

Windows 11 questions

Iriun worked on Windows 10 but not after upgrading to Windows 11
The upgrade resets camera privacy settings. Go to Settings → Privacy & security → Camera and re-enable all three access toggles. Also recheck the Windows Firewall exceptions — they may have been reset during the upgrade.
Iriun webcam windows 11 not connecting
Windows 11 has stricter network access controls for desktop apps. Add Iriun to the firewall (both Private and Public), confirm both devices are on the same Wi-Fi, and try USB mode as an alternative. See the not connecting guide.
