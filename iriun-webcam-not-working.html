Iriun Webcam not working on Windows — fix guide 2026

Iriun Webcam not working on Windows? Check the quick list: PC client running, camera selected, permissions enabled. Then fix with driver reset or clean reinstall.

Start with the checklist below. Most "Iriun not working" reports are actually one of three issues: PC client not running, wrong camera selected in the app, or Windows camera permissions blocked.
Quick checklist

Iriun not working — check these first

  • PC client is running — open Iriun Webcam on Windows before the phone app
  • Phone app is open and connected — you should see the camera preview on your phone
  • Correct camera selected in your app — choose "Iriun Webcam" not your PC webcam
  • Camera permissions granted — Windows Settings → Privacy → Camera → allow app access
  • Iriun appears in device list — if not, reboot Windows after installation
Common causes

Why Iriun is not working

Iriun not working in Zoom or Teams
App opened before Iriun connected, or wrong camera selected
Close app, start Iriun + connect phone, reopen app, select Iriun Webcam
Iriun not working after Windows update
Camera permissions reset or driver conflict
Settings > Privacy > Camera > re-enable app access
Iriun not working on Windows 11
Stricter app permissions and firewall in Windows 11
See Windows 11 specific guide for permission and firewall steps
Iriun not working — black screen
Camera permission denied or driver issue
Check privacy settings and consider a clean reinstall
Iriun not working after phone app update
Version mismatch between phone app and PC client
Update PC client to match phone app version
Camera permissions

Fix Windows camera permissions

Windows Settings
Settings > Privacy & security > Camera
# Make sure these are all ON:
✓ Camera access (system level)
✓ Let apps access your camera
✓ Let desktop apps access your camera
# Then restart Iriun PC client
Full reset

Clean reinstall if nothing else works

  • 1

    Uninstall Iriun from Windows

    Settings → Apps → Iriun Webcam → Uninstall.

  • 2

    Remove from Device Manager

    Right-click Start → Device Manager → Cameras → right-click Iriun Webcam → Uninstall device.

  • 3

    Reboot and reinstall

    Restart Windows, download and run IriunWebcam-2.9.5.exe fresh. See full reinstall guide.

FAQ

Not working questions

Iriun worked yesterday but not working today
Most likely cause: Windows update reset camera permissions. Check Settings → Privacy → Camera and re-enable access. Also restart the Iriun PC client and reconnect the phone.
Iriun PC client opens but phone cannot connect
See the dedicated not connecting guide. Common fix: add Iriun to Windows Firewall exceptions and confirm both devices are on the same Wi-Fi network.
