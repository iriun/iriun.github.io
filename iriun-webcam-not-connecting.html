Iriun Webcam not connecting on Windows — fix guide 2026

Iriun Webcam not connecting to your PC? Start the PC client first, check both devices are on the same Wi-Fi, add Iriun to Windows Firewall, or switch to USB mode.

The most common cause: PC client not running when you open the phone app. Start the PC client first, then open the phone app. This fixes ~70% of connection issues.
Fix 1 — fastest

Start PC client before the phone app

  1. Open Iriun Webcam on your Windows PC — wait until it shows "Waiting for connection"
  2. Then open the Iriun app on your phone
  3. The phone should find the PC within a few seconds
Always open the PC client first. The phone app looks for the PC client on startup — if the client is not running, it will not find it.
Fix 2

Confirm both devices are on the same Wi-Fi

Iriun uses your local network to discover devices. If your phone is on mobile data or a different Wi-Fi network, it cannot find the PC.

  • On your phone: Settings → Wi-Fi → confirm network name matches your PC
  • On Windows: click the Wi-Fi icon in the taskbar → confirm connected to the same router
  • If your router has both 2.4GHz and 5GHz networks with different names, make sure both devices are on the same band
Fix 3

Add Iriun to Windows Firewall

Windows Firewall blocks Iriun's network discovery by default. This is the second most common cause of connection failure:

Windows Defender Firewall
Control Panel > Windows Defender Firewall
> Allow an app or feature through Windows Defender Firewall
> Change settings > Allow another app > Browse
> Select: C:\Program Files\Iriun Webcam\IriunWebcam.exe
# Enable both Private AND Public checkboxes
# Click OK and retry connection
Fix 4 — USB

Try USB instead of Wi-Fi

If Wi-Fi connection keeps failing, USB is more reliable and has lower latency:

  • Android: Enable USB debugging (Settings → Developer Options → USB Debugging), plug in USB cable, trust the connection on your phone
  • iPhone: Plug in Lightning or USB-C cable, trust the PC when prompted on your iPhone, then open Iriun on both devices
USB mode bypasses all Wi-Fi and firewall issues. If Wi-Fi connection is unreliable, switch to USB for a stable connection.
Fix 5

Restart both devices

If none of the above fixes work:

  • Close the Iriun app on your phone
  • Close the PC client on Windows
  • Reboot your Windows PC
  • Reopen the PC client, wait for "Waiting for connection"
  • Reopen the phone app
FAQ

Not connecting questions

Why is Iriun webcam not connecting on Windows 11?
Windows 11 has stricter network isolation for apps. Make sure Iriun is allowed through the firewall (both Private and Public). Also check: Settings → Privacy & security → Camera → Iriun Webcam is enabled. See the Windows 11 guide.
Iriun connects but immediately disconnects
This is usually a Wi-Fi stability issue. Switch to USB mode for a stable connection. If using Wi-Fi, try connecting to the 5GHz band instead of 2.4GHz for better stability and lower latency.
"Iriun webcam requires PC client" error on phone
The PC client is not running. Open Iriun Webcam on your Windows PC first, wait for it to show "Waiting for connection", then open the phone app.
