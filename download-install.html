Install guide

Download & install Iriun Webcam for Windows — setup guide

Install Iriun Webcam on Windows 10 and 11. Download the PC client, install the phone app on iPhone or Android, connect and select Iriun as your camera in Zoom, Teams or OBS.

A quick reCAPTCHA check will appear — complete it and the download starts automatically.
Windows 10 / 11Version 2.9.5Free to use
You need to install Iriun on both your Windows PC and your phone. The PC client receives the video stream; the phone app captures and sends it.
Step 1 — PC

Install Iriun PC client on Windows

  • 1

    Download the PC client

    Click the download button above to get IriunWebcam-2.9.5.exe. This is the Windows client that creates the virtual camera device.

  • 2

    Run the installer

    Double-click the .exe. If Windows SmartScreen appears, click More info → Run anyway. The installer sets up the Iriun virtual camera driver.

  • 3

    Launch the Iriun PC client

    After install, open Iriun Webcam from the Start menu. Leave it running in the background — it must be open when you connect from your phone.

Step 2 — Phone

Install Iriun app on your phone

  • 1

    Install from the app store

    iPhone: Search "Iriun Webcam" on the App Store.
    Android: Search "Iriun Webcam" on Google Play.

  • 2

    Connect to the same Wi-Fi

    Make sure your phone and PC are both connected to the same Wi-Fi network. For USB connection, enable USB debugging on Android or trust the connection on iPhone.

  • 3

    Open the app and connect

    Open the Iriun app on your phone. It scans the local network and connects to the PC client automatically. You should see the camera preview start streaming.

Verify it works

Test Iriun in your app

Once connected, open any video app and select Iriun Webcam as the camera:

  • Zoom: Settings → Video → Camera → Iriun Webcam
  • Teams: Settings → Devices → Camera → Iriun Webcam
  • OBS: Add source → Video Capture Device → select Iriun Webcam
  • Discord: Settings → Voice & Video → Video Settings → Iriun Webcam
If Iriun Webcam does not appear in the camera list, make sure the PC client is running and your phone is connected to it.
FAQ

Install questions

Iriun not showing in camera list after install
The PC client must be running before opening your video app. Close and reopen Zoom/Teams/OBS after starting the Iriun client. If still missing, reboot Windows — the virtual camera driver sometimes needs a restart to register.
Windows Defender blocks the installer
Click More info → Run anyway. The Iriun installer installs a virtual camera driver (WDM driver) which Windows Defender sometimes flags. This is expected behaviour for virtual camera software.
Do I need to install anything on iPhone?
Yes — install the Iriun Webcam app from the App Store. Both the PC client and the phone app must be running and on the same Wi-Fi network. See the iPhone setup guide.
