Step-by-step installation

1) Download
Click the button above to get IriunWebcam-2.9.5.exe from iriun.com.
2) Run installer
Double‑click the file and follow the setup wizard. Allow the app to make changes when asked.
3) Finish setup
Complete installation and restart your video apps if they were open.
4) First run
Open Iriun on your phone first, then on your PC. Select the rear camera for the best quality.
5) Permissions
Windows 11/10: Settings → Privacy & security → Camera → Allow apps to access your camera.
6) Verify
In Zoom/Teams/Meet, choose Iriun Webcam in the camera list. In OBS, add Video Capture Device.

Quick verification in popular apps

  • Zoom: Settings → Video → Camera: Iriun Webcam (enable HD if available).
  • Microsoft Teams: Settings → Devices → Camera: Iriun Webcam.
  • Google Meet: Settings → Video → Camera: Iriun Webcam.
  • OBS Studio: Sources → “+” → Video Capture Device → Device: Iriun Webcam.

If the installer won’t start

  • Right‑click the file → Run as administrator.
  • Temporarily allow the installer through your antivirus if it blocks unknown apps.
  • Ensure you downloaded from the official link: https://iriun.com/IriunWebcam-2.9.5.exe
