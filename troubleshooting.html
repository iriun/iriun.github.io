Fix errors

Iriun Webcam troubleshooting on Windows — fix all common errors

Fix Iriun Webcam issues on Windows: phone not connecting, camera not showing in Zoom and Teams, black screen, firewall block and virtual camera driver problems.

Most Iriun issues fall into one of three categories: connection problems (phone and PC not finding each other), camera not appearing in apps, or driver issues on Windows. Start with the fix that matches your symptom.
Not connecting

Iriun phone not connecting to PC

Phone shows "Looking for computer" and never connects
PC client not running, or phone and PC on different networks
Start PC client first, confirm both are on same Wi-Fi
Connected on Wi-Fi but video is black or frozen
Firewall blocking UDP traffic between devices
Add Iriun to Windows Defender Firewall exceptions
USB mode not working on Android
USB debugging not enabled or wrong USB mode selected
Enable USB debugging in Developer Options on Android
"Please start Iriun Webcam" error on phone
PC client is not running
Open Iriun Webcam on Windows PC first, then open phone app
Camera not detected

Iriun Webcam not showing in Zoom / Teams / OBS

Iriun Webcam missing from camera dropdown
Virtual camera driver not installed or app opened before client
Restart the app after Iriun client is running; reboot if needed
Camera appears but shows black screen
Permission denied or driver conflict
Check Windows camera privacy settings; allow the app to use camera
Iriun shows in OBS but not in Zoom/Teams
Some apps need to be restarted after Iriun connects
Close and reopen Zoom or Teams while Iriun is running
Firewall fix

Add Iriun to Windows Firewall

Windows Defender Firewall
# Open firewall settings:
Control Panel > Windows Defender Firewall
> Allow an app or feature through Firewall
> Change settings > Allow another app
> Browse to: C:\Program Files\Iriun Webcam\IriunWebcam.exe
# Check both Private and Public network boxes
Driver reinstall

Reinstall the Iriun virtual camera driver

  • 1

    Uninstall Iriun completely

    Settings → Apps → Iriun Webcam → Uninstall. Also remove any Iriun entries from Device Manager under Cameras or Imaging devices.

  • 2

    Reboot Windows

    Restart your PC to fully remove the virtual camera driver.

  • 3

    Reinstall fresh

    Download and run IriunWebcam-2.9.5.exe again. The driver reinstalls cleanly. See clean reinstall guide.

FAQ

Troubleshooting questions

Iriun worked before but stopped after Windows Update
Windows updates sometimes reset camera privacy permissions. Check: Settings → Privacy → Camera → make sure your apps are allowed to access the camera. Also reboot the Iriun PC client.
Initialization failed — problems with audio driver
This error means Iriun cannot initialise the audio output. Fix: uninstall Iriun completely, reboot, reinstall. If the error persists, check Device Manager for any yellow warning icons under Sound, video and game controllers.
