Uninstall & reinstall Iriun Webcam on Windows — clean install guide

Clean uninstall Iriun Webcam on Windows: remove from Settings, delete driver from Device Manager, clear leftover files, reboot and reinstall fresh.

A clean reinstall fixes most persistent Iriun issues: black screen, not detected, audio initialisation errors. It takes about 5 minutes.
Step 1

Uninstall Iriun Webcam from Windows

  • 1

    Close the Iriun PC client

    Right-click the Iriun icon in the system tray → Exit. Or close it from Task Manager.

  • 2

    Uninstall from Settings

    Settings → Apps → search for Iriun → click Iriun Webcam → Uninstall. Follow the uninstall wizard.

  • 3

    Remove from Device Manager

    Right-click Start → Device Manager → expand Cameras or Imaging devices → right-click Iriun Webcam → Uninstall device → check "Delete driver software" → Uninstall.

Step 2

Remove leftover files

cmd.exe — Administrator
# Remove Iriun program files:
C:\> rmdir /s /q "C:\Program Files\Iriun Webcam"
# Remove AppData entries:
C:\> rmdir /s /q "%APPDATA%\Iriun"
C:\> rmdir /s /q "%LOCALAPPDATA%\Iriun"
# These may not exist — ignore "not found" errors
Step 3

Reboot and reinstall

  • 1

    Restart Windows

    Reboot your PC. This ensures the virtual camera driver is fully removed from the system.

  • 2

    Download fresh installer

    Get the latest IriunWebcam-2.9.5.exe from the download page.

  • 3

    Install and test

    Run the installer, open the PC client, connect your phone and test in Zoom or Teams.

FAQ

Reinstall questions

After reinstall, Iriun still not showing in camera list
Make sure you rebooted Windows after uninstalling. The virtual camera driver registers during the first boot after installation. If still missing, open Device Manager and check for any yellow warning icons under Cameras.
Iriun keeps crashing after reinstall
Check if another virtual camera software (OBS Virtual Camera, ManyCam, DroidCam) is conflicting. Try disabling other virtual cameras in Device Manager, then reopen Iriun.
