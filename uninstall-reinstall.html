Uninstall & Clean Reinstall Guide for Iriun Webcam on Windows

If Iriun isn’t detected or you see persistent black screens, a clean reinstall usually helps. Remove the app and its virtual camera device, reboot, then install fresh.

Troubleshooting USB vs Wi‑Fi tips
Version: 2.9.5 • OS: Windows 11 / 10 • File: IriunWebcam-2.9.5.exe
Warning: Be careful in Device Manager and only remove the Iriun virtual camera. Don’t uninstall your real webcam or unrelated devices.

Before you start

  • Close Zoom, Teams, OBS and Iriun
  • Save your work — you will reboot the PC
  • Have admin rights on Windows
Last updated:
—

Step‑by‑step: clean uninstall

1) Quit all video apps — Close Zoom, Teams, OBS and exit the Iriun tray app.
2) Uninstall Iriun — Settings → Apps → Installed apps → Iriun Webcam → Uninstall.
3) Open Device Manager — Press Win+X → Device Manager → Expand Cameras (or Imaging devices).
4) Remove the virtual camera — Right‑click Iriun Webcam → Uninstall device → Check “Delete the driver software for this device” (if shown) → OK.
5) Show hidden devices — View → Show hidden devices. Remove any greyed‑out Iriun camera entries.
6) Reboot Windows — Restart your PC to complete driver removal.

Reinstall and verify

7) Download the installer — Get IriunWebcam-2.9.5.exe from the official link and run it.
8) Install — Follow the wizard; allow Windows to make changes when prompted.
9) Start order — Open the phone app first, then the Iriun Windows app, then your video app.
10) Verify in apps — In Zoom/Teams/Meet pick Iriun Webcam. In OBS add it as a Video Capture Device.

If detection still fails, revisit Troubleshooting and confirm Windows camera privacy settings.
