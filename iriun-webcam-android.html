Android guide

Iriun Webcam Android setup for Windows — USB & Wi-Fi guide

Use your Android phone as a webcam on Windows with Iriun. Enable USB Debugging for USB mode, connect via Wi-Fi or cable and select Iriun Webcam in Zoom, Teams or OBS.

Iriun Webcam works on Android 5.0 and later. USB mode requires enabling USB Debugging in Developer Options — it sounds technical but takes under a minute.
Install

Set up Iriun on Android

  • 1

    Install Iriun on Windows PC

    Download and run IriunWebcam-2.9.5.exe. Open the Iriun PC client and leave it running.

  • 2

    Install Iriun on Android

    Open Google Play, search Iriun Webcam and install. The app is free.

  • 3

    Connect via Wi-Fi or USB

    Wi-Fi: Connect Android and PC to the same Wi-Fi network. Open the Iriun app — it finds the PC automatically.
    USB: See the USB setup section below.

  • 4

    Grant camera permission

    On first launch, tap Allow when Iriun asks for camera access.

USB mode on Android

Enable USB Debugging for USB connection

  • 1

    Unlock Developer Options

    Settings → About phone → tap Build number 7 times. You will see "You are now a developer!" message.

  • 2

    Enable USB Debugging

    Settings → Developer Options → enable USB Debugging.

  • 3

    Plug in USB cable

    Use a data cable (not charge-only). When Android asks "Allow USB debugging?", tap Allow.

  • 4

    Open Iriun apps

    Open the PC client on Windows, then open the Iriun app on Android. It detects the USB connection automatically.

FAQ

Android questions

Iriun Android not connecting via USB
Check USB Debugging is enabled in Developer Options. When you plug in the cable, Android shows an "Allow USB debugging?" prompt — tap Allow. Also make sure you are using a data cable, not a charge-only cable. Try a different USB port on your PC.
USB Debugging not showing in Settings
You need to unlock Developer Options first. Go to Settings → About phone → tap Build number exactly 7 times. The Developer Options menu then appears in Settings (sometimes under System → Developer Options).
Iriun Android camera quality is low
In the Iriun Android app, tap the settings icon and increase the resolution. Higher resolutions work best over USB. On Wi-Fi, stick to 720p for stable performance. The paid version unlocks 1080p.
